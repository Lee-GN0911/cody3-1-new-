# 요즘 모기가 줄어든 걸까?

서울 빨간집모기 2008~2023년 유문등 채집 자료와 기상 자료를 결합해, "모기가 줄었다"는 체감과 "날이 더워서 그렇다"는 설명을 데이터로 확인한 시계열 분석 프로젝트입니다.

**분석 리포트 → [REPORT.md](REPORT.md)**

## 결론 세 줄

- 모기 총량은 **줄지 않았다.** 4~11월 전체 장기 추세는 p=0.881로 사실상 0.
- 대신 **시기가 밀렸다.** 여름(6~8월) −25~35%, 봄·가을 +8~149%.
- **"더워서 없다"는 크기가 안 맞는다.** 늘어난 폭염으로 설명되는 여름 감소는 −1.9%, 실제는 −31.4%.

## 빠른 실행

```bash
pip install -r requirements.txt
python src/step1_preprocess.py   # 먼저 실행 (원자료 → 478주 분석표)
python src/step2_explore.py      # 이후 step2~6은 순서 무관
```

전체 실행 순서는 [REPORT.md 8절](REPORT.md#8-실행-방법)에 있습니다.

## 분석 흐름

| 단계 | 하는 일 | 답하는 질문 |
|---|---|---|
| 1 | 두 자료를 주 단위로 결합, 결측·이상치 처리 | — |
| 2 | 기본 정보 확인, 어디가 비었는지 파악 | — |
| 3 | 계절 보정 후 장기 변화 | 모기는 정말 줄었는가 |
| 4 | 기온·폭염일 추세 | 온도는 실제로 올랐는가 |
| 5 | 기온 구간별 통계 | 무엇과 비교할 것인가 |
| 6 | 회귀 + 온난화의 몫 | 더워서 줄었다는 말은 맞는가 |

## 데이터

| 자료 | 출처 | 기간 | 규모 |
|---|---|---|---|
| 유문등 채집 모기 | **서울 열린데이터광장** (서울시 보건환경연구원) | 2008~2023, 4~11월 | 478주 |
| 기상 (기온·강수·습도) | Open-Meteo Historical Weather API (ERA5) | 2008~2023 | 5,844일 |

두 자료 모두 저장소에 포함돼 있습니다. 기상 자료는 `python src/step0_collect_weather.py`로 다시 받을 수 있습니다.

## 원자료에 대한 주의

분석 중 원자료에서 두 가지 결함을 발견했습니다. 자세한 내용은 [REPORT.md 3.3~3.4절](REPORT.md#33-이상치--같은-0이라도-성격이-다르다)에 있습니다.

- 2009·2010년 사이 6개 주차의 값이 정확히 일치합니다 (복사 오류로 의심되나 확정 불가, 그대로 두고 명시)
- 2009년 9월 3주는 다른 종 418마리가 잡혔는데 빨간집모기만 0입니다 (기록 오류로 보아 제외)

## 환경

Python 3.10 이상. 의존성은 `requirements.txt` 참조.

그래프에 한글이 들어가므로 한글 폰트가 필요합니다. Windows(맑은 고딕)와 macOS(AppleGothic)는 기본 설치돼 있고, 리눅스에서 깨진다면 `sudo apt install fonts-nanum` 후 다시 실행하세요. `src/config.py`가 설치된 폰트를 자동으로 찾고, 못 찾으면 경고를 출력합니다.
